# Rebecca Mars - Website

Professional website for Rebecca Mars, independent French–English interpreter based in Geneva.

## Features

- **Bilingual Support** — French & English (toggle in header)
- **Currency Toggle** — CHF & EUR pricing display
- **Responsive Design** — Works on desktop, tablet, mobile
- **Premium Styling** — Professional Navy + Gold color scheme
- **Navigation Menu** — Dropdown menu for easy section access
- **Contact Form** — Quote request form with validation
- **FAQ Section** — Expandable frequently asked questions
- **Accessibility** — WCAG compliant with semantic HTML

## Sections

1. **Hero** — Introduction with call-to-action
2. **Services** — 6 service offerings with pricing
3. **Pricing** — Detailed pricing table (CHF/EUR)
4. **Why Choose** — 4 key differentiators
5. **About** — Professional bio and credentials
6. **Contact** — Contact form and information
7. **FAQ** — Common questions and answers

## Live Site

Deployed on Netlify: [www.rebecca-mars.fr](https://www.rebecca-mars.fr)

## Development

To update the website:

1. Clone this repository
2. Edit `index.html` as needed
3. Commit and push to GitHub
4. Netlify will automatically deploy

## Customization

Update these sections in `index.html`:

- **Hero image placeholder** — Replace with actual photo (line ~400)
- **Contact details** — Phone numbers, LinkedIn URL
- **FAQ answers** — Replace placeholders with real answers
- **Legal pages** — Add privacy policy, terms, cookie policy links
